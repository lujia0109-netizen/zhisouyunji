# 公开展示范围

本目录是独立准备的 GitHub 展示包，可将其内容作为新仓库的根目录上传。不要把上级工作目录、内部程序包或授权管理目录一同上传。

## 包含内容

- 项目介绍和技术架构；
- 三张实际 UI 窗口的演示数据截图；
- 两张独立 SVG 流程图；
- 可运行的标准库 Mock 示例与测试。

## 截图说明

截图专门加载公开演示数据生成，所有操作按钮已禁用，没有连接设备或发送真实提问。链接为 example.com 占位内容，时间为模拟值。截图使用已有客户端界面，但本仓库不提供该客户端源码或安装程序。

## 代码说明

示例展示接口、进程内互斥、错误返回和 JSON 保存，不包含核心识别逻辑、设备控制指令、网络响应解析、签发私钥或授权绕过代码。不应将其部署为生产调度系统。

## 发布状态

本包仅在本地准备，尚未创建 GitHub 仓库或推送内容。公开不自动等于授予开源许可，本包未擅自添加 MIT 等许可证；对外提供复用授权时，请由项目权利人明确许可证范围。
